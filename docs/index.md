# pyPuppenclaw

`pyPuppenclaw` wraps the Puppenclaw daemon for Python callers. It manages bootstrap from a local Puppenclaw checkout, writes isolated daemon config, and exposes a typed client for sessions, orchestration, site status, and logs.

The documentation site is designed to deploy through Read the Docs from this repository's `.readthedocs.yaml`.
